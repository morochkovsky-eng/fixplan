# Единая библиотека FixPlan

С 10 сентября 2026 каноническая витрина: https://fixplan-iota.vercel.app/ui-lab.
Приложение и витрина являются маршрутами одной Next.js-сборки, а не двумя версиями библиотеки.

## Источники

- `components/ui/`: Button, Input, Select, Tabs, Badge, Card и остальные примитивы.
- `components/ai-elements/`: компоненты ассистента.
- `app/globals.css`: общие цвета, типографические токены, адаптивные правила.
- `components/product-header.tsx`: общая шапка.
- `app/ui-lab/`: документация, тестовый контент и компоновка примеров. Это потребитель библиотеки, не источник второй реализации контролов.

Приложение не загружает CSS с публичной витрины по сети. Оба используют одни и те же локальные модули в одной публикации. Изменение общего компонента отражается на обоих маршрутах при следующем деплое основного проекта `fixplan`.

## Правила изменений

1. Цвета и общие свойства меняются в токенах и `components/ui`, а не через `.candidate*` в витрине.
2. Варианты задаются через API компонента: `variant="success"`, `size="xs"` и т. п. Нельзя повторять их CSS отдельно в примере.
3. CSS витрины отвечает за оглавление, расположение примеров, предметную компоновку тестового узла и явно обозначенную демонстрацию hover/focus. Размеры, цвета и радиусы примитивов не переопределяются.
4. Новое свойство компонента сначала добавляется в общий компонент, затем демонстрируется в каталоге. Не создавать временный вариант только в UI Lab.
5. Проверять приложение и витрину на desktop/mobile, а затем публиковать основной проект один раз.

Figma остаётся источником согласованных дизайн-решений. Изменения из Figma переносятся в код явно с проверкой, а не автоматически во время работы браузера.

## Старый адрес

`fixplan-ui-lab-public-20260909.vercel.app/ui-lab` и вложенные маршруты перенаправляются на основной сайт кодом 308. Путь и query сохраняются; браузер сохраняет fragment-ссылку на раздел.

Правило ограничено старым хостом и `/ui-lab`, поэтому не создаёт петлю на основном сайте и не перенаправляет API. Старый Vercel-проект сохранён для совместимости со ссылками; новые версии библиотеки отдельно туда публиковать не нужно. Перенаправление закрепляется однократной публикацией этого правила в старый проект.

## Проверки

`tests/ui-library.test.mjs` запрещает возврат кандидатных обёрток и отдельной палитры примитивов в CSS витрины, проверяет ограничение редиректа по хосту и пути. Визуальная проверка остаётся обязательной: статические тесты не проверяют все возможные переопределения CSS.
