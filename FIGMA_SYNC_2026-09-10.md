## Где изменено

- `app/globals.css`: общие цвета и размеры подписей; хедер, навигация, сетка узла, чат.
- `components/ui/button.tsx`, `badge.tsx`, `tabs.tsx`: подписи используют единый токен непосредственно в компоненте, в том числе при композиции с триггерами меню.
- `components/product-header.tsx`: общий хедер; активный пункт автоматически попадает в видимую часть горизонтального меню при переходе.
- `components/dashboard-clock.tsx`: компактные часы с датой и годом, часовой пояс из настроек квартиры.
- `app/page.tsx`: верхняя навигация во всех разделах; новый AssetDetail; сворачивание чата без сброса его истории/черновика; Escape закрывает панель; тема доступна в настройках.
- `app/ui-lab/asset/page.tsx`, `asset-demo.module.css`, `app/ui-lab/ui-lab.module.css`: общий хедер тестового узла и обновлённые подписи/Notice.

## Сохранённые функции и локальные решения

- Мобильный хедер следует 48:10: логотип и квартира, без часов. Тема доступна в настройках. Вопрос об оставлении часов на mobile отправлен владельцу, ответа пока нет.
- Добавление квартиры доступно через пункт селекта на mobile, где отдельной кнопки «+» в макете нет.
- Дополнительная вкладка «Медиа» сохранена: удалять существующий сценарий загрузки фотографий ради четырёх вкладок демонстрационного узла нельзя.
- Редактирование паспорта продолжает открывать существующий редактор на плане. Поля и сохранение не заменялись новым непроверенным диалогом.
- Карточки заданий узла используют реальные связи `allowedAssetIds` и открывают существующий отчёт. Макетные мастера и задания не подмешиваются в рабочие данные.
- Текст предупреждения «Не снимать защитную крышку…» остаётся только в тестовом узле. Это не универсальная инструкция для любого оборудования.
- Между desktop/mobile выбран промежуточный перенос хедера на две строки при 1200 px и одноколоночный overview при 1040 px. Это адаптация между предоставленными фреймами, не самостоятельные значения из Figma.
- Более светлый success-цвет перенесён точно. Контраст всех сочетаний требует отдельной проверки перед объявлением соответствия требованиям доступности; оттенок самовольно не затемнялся.

## Проверка

Сценарий `scripts/verify-figma-ui.mjs` запускается с Playwright/Chrome против локального preview. Все обращения к API перехватываются тестовыми ответами; любые операции изменения блокируются. Рабочие данные не изменяются.

- 36 экранов: dashboard, список узлов, план, задания, документы, коммуналка, журнал, настройки, узел на 1440/1280/390/360 CSS px.
- Дополнительно: вкладки узла, редактор паспорта, селект квартиры, диалог нового объекта, раскрытие/сворачивание чата, тёмный узел.
- Собраны геометрия контролов, computed font-size/radius, ширина документа. Переполнения страницы не обнаружены, JS-ошибок в проверенном сценарии нет.
- Скриншоты и измерения: `outputs/figma-sync-2026-09-10/` (локальные артефакты, исключены из git). Длинные списки с content-visibility нужно смотреть по viewport-снимкам: полностраничный снимок не рендерит все невидимые строки.
- Source-тесты: 39 успешно. TypeScript и lint изменённых файлов проходят.
- Production-сборка через `next build --webpack` успешна. Обычный Turbopack build упал на запрете локального bind дочернего CSS-процесса; это ограничение окружения, не объявлено успешным запуском.

Ограничения: нет проверки реальной отправки сообщений, голоса, загрузки файлов, платежей и записей в Supabase. Мобильная проверка выполнена в Chrome с CSS-viewport, не на физическом Safari с экранной клавиатурой. Гостевые страницы мастера/клинера, вход и все возможные состояния форм не входят в 36 экранов. Они получают общие токены, но не объявляются визуально принятыми. Эталонные регрессионные снимки не утверждены.

## Приёмка

Открыть `/assets/s-wc-boiler-control?ui-preview=1` и `/ui-lab/asset` на текущем localhost:3010. Проверить новый хедер, компактность узла, открытый/закрытый чат, затем общие страницы. Публичные Vercel-развёртывания в рамках этой синхронизации не обновлялись.
